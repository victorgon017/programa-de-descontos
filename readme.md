# 🧮Programa de cálculo de descontos 

## 📌Objetivo
Programa desenvolvido para calcular os descontos aplicados no valor de uma compra e apresentar o valor final com os descontos.

## 🖥️Linguagem de programação
A linguagem de programação utilizada no programa foi o Python.

### ✔️Pré-requisito
* Ter o **Python 3** instalado no computador.

### 💡Passo a passo
Informe ao programa:
- O valor da compra

Após o valor da compra ser informado, o programa calcula automaticamente a porcentagem de desconto (5%, 10% ou 15%) e exibe o valor do desconto e o valor final a pagar.
